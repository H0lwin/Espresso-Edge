
# ☕ اسپرسو اِج - نوشیدنی بی‌نظیر شما در انتظار است

**توسعه یافته توسط H0lwin**

**مشاهده مخزن:** [https://github.com/heroinsh/Espresso-Edge/](https://github.com/heroinsh/Espresso-Edge/)

[English (نسخه انگلیسی)](./README.md)

به **اسپرسو اِج** خوش آمدید، یک وب اپلیکیشن پیشرونده (PWA)، مدرن و فراگیر که طراحی شده تا تجربه غنی یک کافی‌شاپ سطح بالا را مستقیماً به نوک انگشتان شما بیاورد. اسپرسو اِج یک سفر کاربری یکپارچه و لذت‌بخش را ارائه می‌دهد، از مرور منوی تعاملی ما گرفته تا آشنایی با داستان ما.

## ✨ ویژگی‌های کلیدی

اسپرسو اِج سرشار از ویژگی‌هایی است که برای جذب و رضایت شما طراحی شده‌اند:

*   **بخش Hero جذاب در صفحه اصلی:** خوش‌آمدگویی بصری خیره‌کننده با یک ویدیو یا پس‌زمینه متحرک جذاب و یک دکمه فراخوان واضح.
*   **منوی بسیار تعاملی:** کاوش در میان قهوه‌ها، شیرینی‌جات و اسنک‌ها با افکت‌های شناور نرم، انیمیشن‌های اسکرول، فیلترهای دسته‌بندی بصری و یک نوار جستجوی سریع در سمت کاربر.
*   **صفحه "داستان ما" متحرک:** کشف سفر اسپرسو اِج از طریق یک جدول زمانی متحرک و معرفی زیبای اعضای تیم.
*   **فرم تماس جذاب:** تماس از طریق یک فرم متحرک با اعتبارسنجی آنی و آیکون‌های رسانه‌های اجتماعی تعاملی.
*   **ناوبری پویا و چسبنده:** یک نوار ناوبری پایدار با قابلیت اسکرول نرم، که در دستگاه‌های موبایل برای دسترسی مداوم به یک منوی همبرگری متحرک تبدیل می‌شود.
*   **فوتر اطلاعاتی:** دسترسی سریع به ساعات کاری، لینک‌های اجتماعی و یک فیلد ثبت‌نام خبرنامه تعاملی.
*   **اپلیکیشن وب پیشرونده (PWA):** قابل نصب بر روی دستگاه شما برای تجربه‌ای شبیه به اپلیکیشن، با نشانگر وضعیت آفلاین.
*   **طراحی واکنش‌گرا:** کامپوننت‌های کاملاً واکنش‌گرا که تجربه عالی را در هر دستگاهی تضمین می‌کنند.

## 🚀 پشته فناوری

اسپرسو اِج با استفاده از یک پشته فناوری مدرن و قوی ساخته شده است:

*   **فریمورک:** [Next.js](https://nextjs.org/) (App Router)
*   **زبان:** [TypeScript](https://www.typescriptlang.org/)
*   **کتابخانه UI:** [React](https://reactjs.org/)
*   **استایل‌دهی:** [Tailwind CSS](https://tailwindcss.com/)
*   **کامپوننت‌های UI:** [ShadCN UI](https://ui.shadcn.com/)
*   **انیمیشن‌ها:** [Framer Motion](https://www.framer.com/motion/)
*   **PWA:** فعال شده از طریق `next-pwa` برای تولید Service Worker و فایل Manifest.

## 🏁 شروع به کار

برای راه‌اندازی یک نسخه محلی، این مراحل ساده را دنبال کنید.

### پیش‌نیازها

اطمینان حاصل کنید که موارد زیر را نصب کرده‌اید:
*   Node.js (نسخه ۱۸ یا بالاتر توصیه می‌شود)
*   npm یا yarn

### اجرای سرور توسعه

*   **اپلیکیشن اصلی:**
    ```bash
    npm run dev
    ```
    آدرس [http://localhost:9002](http://localhost:9002) (یا پورتی که در اسکریپت `dev` شما مشخص شده) را در مرورگر خود باز کنید تا نتیجه را ببینید.

## 📜 اسکریپت‌های موجود

در دایرکتوری پروژه، می‌توانید اجرا کنید:

*   `npm run dev`: برنامه را در حالت توسعه اجرا می‌کند.
*   `npm run build`: برنامه را برای تولید نهایی بیلد می‌کند.
*   `npm run start`: سرور تولید نهایی را راه‌اندازی می‌کند.
*   `npm run lint`: کدها را با استفاده از پیکربندی داخلی ESLint در Next.js بررسی می‌کند.
*   `npm run typecheck`: TypeScript را برای بررسی خطاهای نوع اجرا می‌کند.

## 🎨 دستورالعمل‌های استایل‌دهی

اسپرسو اِج به دنبال ایجاد حسی گرم، شیک و سطح بالا است:

*   **رنگ اصلی:** قهوه‌ای تیره (`#6F4E37`) - القاکننده گرما و راحتی.
*   **رنگ پس‌زمینه:** برنزه روشن (`#F5E7D2`) - پس‌زمینه‌ای نرم و دعوت‌کننده فراهم می‌کند.
*   **رنگ تاکیدی:** نارنجی سوخته (`#CC6633`) - عناصر کلیدی تعاملی را برجسته می‌کند.
*   **فونت‌ها:**
    *   عناوین: 'Playfair Display' (سریف)
    *   متن اصلی: 'PT Sans' (سنس‌سریف)
*   **آیکون‌ها:** عمدتاً از `lucide-react` برای ظاهری تمیز و مدرن استفاده می‌کند.
*   **بافت‌ها:** طراحی شامل بافت‌های دنج و ظریف است.

## 📱 اپلیکیشن وب پیشرونده (PWA)

اسپرسو اِج یک PWA است که ارائه می‌دهد:
*   **قابلیت نصب:** برنامه را با یک درخواست نصب کاربرپسند به صفحه اصلی دستگاه خود اضافه کنید.
*   **نشانگر آفلاین:** کاربران از وضعیت آنلاین/آفلاین خود مطلع می‌شوند.
*   **عملکرد بهبود یافته:** Service Worker ها به ذخیره دارایی‌ها برای زمان بارگذاری سریع‌تر و دسترسی آفلاین به صفحات بازدید شده قبلی کمک می‌کنند.
